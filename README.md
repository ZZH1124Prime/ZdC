# ZdC

ZdC 是面向 Windows 的轻量应用直连工具，目标是在保留现有代理使用习惯的同时，让用户指定的应用直接联网。

## 当前状态

项目处于规划阶段，目前仅建立说明文件与 Git 忽略规则，尚无程序实现或安装包。首次提交由项目所有者完成，之后再开始开发。

## 目标功能

- 添加、查看和移除需要直连的应用。
- 在工具运行期间，让已登记应用的新连接绕过代理；移除登记后恢复通常的代理行为。
- 退出工具后撤销本工具施加的规则，网络行为重新由系统与现有代理配置决定。
- 提供简洁、现代、清晰易用的 Windows 界面和安装版，按实际需求处理管理员权限。

## 运行语义

设计目标是“先登记，再打开应用”：登记中的应用走直连，其他应用保持原有行为；工具退出后，开启代理时按原有代理规则联网，未开启代理时按原有网络配置直连。规则变更针对新连接，既有连接的处理将在实现阶段确定。关闭窗口与彻底退出的区别应在界面中明确呈现。

## 隐私与实现边界

优先在本机保存应用名单与设置，不规划账号、云端同步或联网行为采集。开发过程保持现有代理与远程连接可用，不以禁用代理或重置全局网络作为实现方式。

## 后续计划

拟采用 .NET 与 WPF 构建 Windows 界面，先确定适配现有代理模式的直连方案，再实现核心行为。具体网络机制、支持范围、依赖和安装流程将在实现验证后补充。项目许可证尚未选定；引入上游代码、组件或素材前，应核对其许可证并保留必要声明。
