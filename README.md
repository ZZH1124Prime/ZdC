# ZdC

Linux 安装版和 Android App 的构建、安装及规则联动说明见 [跨平台预览](ports/README.md)。

ZdC 是面向 Windows 的轻量应用直连工具，目标是在保留现有代理使用习惯的同时，让用户指定的应用直接联网。

## 当前状态

项目处于规划阶段，README 与 Git 忽略规则已完成首次提交，接下来进入方案确定与开发阶段。

## 目标功能

- 添加、查看和移除需要直连的应用。
- 在工具运行期间，让已登记应用的新连接绕过代理；移除登记后恢复通常的代理行为。
- 退出工具后撤销本工具施加的规则，网络行为重新由系统与现有代理配置决定。
- 提供简洁、现代、清晰易用的 Windows 界面和安装版，按实际需求处理管理员权限。

## 运行语义

设计目标是“先登记，再打开应用”：登记中的应用走直连，其他应用保持原有行为；工具退出后，开启代理时按原有代理规则联网，未开启代理时按原有网络配置直连。规则变更针对新连接，界面应明确区分关闭窗口与彻底退出。

## 隐私与实现边界

应用名单与设置采用本地存储，功能范围集中于本机应用的直连管理。网络规则的作用范围限定为已登记应用，并保持现有代理配置与远程连接可用。

## 后续计划

拟采用 .NET 与 WPF 构建 Windows 界面，先确定适配现有代理模式的直连方案，再实现核心行为。开发前明确具体网络机制、支持范围及既有连接的处理方式，并在实现验证后补充依赖与安装流程。项目许可证将在选型阶段确定，引入上游代码、组件或素材时核对许可要求并保留必要声明。

## 游戏与反作弊

请勿将带反作弊的游戏及其启动器加入 ZdC。当前接管方式会向目标进程加载 DLL 并拦截网络 API，可能被反作弊阻止，造成启动失败或被踢出；具体处理取决于游戏规则及检测结果，违规使用也存在账号处罚风险。[BattlEye 官方 FAQ](https://www.battleye.com/support/faq/) 和 [Riot 官方说明](https://support.riotgames.com/en-us/riot/performance/game-memory-access-removed-for-third-party-apps) 均区分了工具拦截与封号，文件加载被阻止本身并不等于账号被封。

暂停直连或退出 ZdC 会停止接管新连接，但已经加载的 DLL 仍驻留到目标进程结束。若误将游戏加入，请移除该项，完全退出游戏及其受控启动器，再从原入口启动；不要尝试绕过反作弊拦截。
